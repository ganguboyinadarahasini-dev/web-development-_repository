My Programming Notes

JavaScript

JavaScript is a powerful programming language mainly used for making websites interactive. It runs in the browser and allows us to handle events, validate forms, and create dynamic content. JavaScript is essential for front-end web development and is also used on the server side with Node.js. Variables are used to store data in JavaScript.

Example: Hello World and variable declaration in JavaScript:

// JavaScript Example - Hello World
let name = "Aman";
let age = 20;

console.log("Hello, " + name);
console.log("You are " + age + " years old");

if (age >= 18) {
    console.log("You are eligible to vote");
}

Java

Java is a popular object-oriented programming language known for its portability and security. It is widely used for building Android apps, enterprise applications, and backend systems. Java follows the principle of Write Once, Run Anywhere (WORA) because of JVM. Class is the most important concept in Java as everything is inside a class.

Example: Hello World and variable in Java:

// Java Example - Hello World
public class Main {
    public static void main(String[] args) {
        String name = "Aman";
        int age = 20;
        
        System.out.println("Hello World");
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
        
        if (age >= 18) {
            System.out.println("Eligible to vote");
        }
    }
}

Python

Python is a simple, readable, and beginner-friendly programming language. It is widely used in data science, artificial intelligence, machine learning, web development, and automation. Python emphasizes code readability and simplicity. Indentation is very important in Python because it defines code blocks instead of braces.

Example: Hello World and variable declaration in Python:

# Python Example - Hello World
name = "Aman"
age = 20

print("Hello World")
print(f"Name: {name}")
print(f"Age: {age}")

if age >= 18:
    print("You are eligible to vote")
else:
    print("You are not eligible")
